🚀 QUICK START (4 STEPS)

Step 1: Start Appium Server
────────────────────────────────────────────────────────────
   Terminal 1:
   $ npx appium

Step 2: Verify Android Device
────────────────────────────────────────────────────────────
   Terminal 2:
   $ adb devices
   
   (Should show emulator or device connected)

Step 3: Run Tests
────────────────────────────────────────────────────────────
   Terminal 3:
   $ pnpm run test:appium
   
   This will:
   ✅ Connect to Appium
   ✅ Launch the app (localhost:5174)
   ✅ Run 101 test cases
   ✅ Generate Excel & JSON reports

Step 4: View Results
────────────────────────────────────────────────────────────
   $ pnpm run test:appium:analysis
   
   Results available:
   📊 tests/appium/results/appium-e2e-results.xlsx
   📄 tests/appium/results/appium-analysis.md
   📋 tests/appium/results/appium-e2e-results.json

🔧 ENVIRONMENT VARIABLES (Optional)

For Mobile Browser Testing (Default):
   APP_URL=http://localhost:5174
   API_URL=https://backend-6o6o.onrender.com/jobs

For Native Android App:
   ANDROID_APP_PACKAGE=com.example.jmi
   ANDROID_APP_ACTIVITY=.MainActivity

For Custom Appium Server:
   APPIUM_HOST=127.0.0.1
   APPIUM_PORT=4723

For Device Testing:
   # Forward port to device
   adb reverse tcp:5174 tcp:5174
   
   # Or use LAN IP
   APP_URL=http://192.168.x.x:5174

🐛 TROUBLESHOOTING

Appium won't connect?
   $ lsof -i :4723 | grep LISTEN | awk '{print $2}' | xargs kill -9
   $ npx appium

Device not found?
   $ adb kill-server && adb start-server
   $ adb devices

Tests timing out?
   - Check device/emulator is responsive
   - Verify network connectivity
   - Check app loads on localhost:5174
